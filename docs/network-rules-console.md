# 防火墙与端口转发即时操作

控制台的防火墙和端口转发不再需要保存、刷新按钮：点击添加、删除或切换防火墙模式，立即提交并应用，成功后更新列表。输入未完成时不会自动提交，失败保留输入并显示居中错误提示。

## 编辑已有条目

每行的“编辑”会将原值回填到单条表单，点击“应用修改”直接更新原条目，不用先删除再添加，也没有整页保存按钮。点击“取消编辑”不发送请求；校验或请求失败时保留输入。后台轮询不会覆盖正在编辑的输入；原条目已被其他操作修改或删除时拒绝提交，避免按过期行号误改其他条目。修改转发的本地端口或目标可能断开对应活动连接。

## 批量添加

展开“批量添加”，每行三列，空格、制表符、英文或中文逗号分隔，空行忽略。

防火墙：`来源 协议 端口`

```text
* tcp 3389
10.7.0.0/16 udp 5000-5010
10.7.1.2 /pvn/tunnel/1.0.0 *
```

来源支持 IP、CIDR 网段和 `*`；协议支持 tcp、udp、全部协议 `*` 和以 `/` 开头的应用流协议。TCP/UDP 端口支持单端口、范围或 `*`。应用流、全部协议沿用原有全端口语义。规则自动去重；添加规则不会擅自改变防火墙模式，按规则放行需要选择 allow-list。

端口转发：`本地端口 目标IP 目标端口`

```text
8080 192.168.1.100 80
8443 192.168.1.100 443
9090 ::1 90
```

端口必须是 1–65535 的整数。本地监听端口不能与已有映射或本批其他行重复；IPv6 目标会自动以方括号拼接。

全部行校验通过后只发送一次整表 PUT；任何非法行都会阻止本批提交并提示行号。操作期间两个面板共用互斥锁，禁止重复请求；轮询不会覆盖提交中的或刚确认的配置。

## 边界

- 添加映射不自动修改防火墙规则；删除映射会断开该端口的活动连接。
- 后端收到配置后会同步监听，但端口占用等监听失败仍需查看日志，接口成功不等于目标服务可访问。
- 本地转发监听绑定所有网卡；物理网卡的访问范围还应由操作系统或容器防火墙控制。
- 接口仍是整表替换，本页串行化只能避免本页并发覆盖，不能解决多个控制台同时编辑的覆盖。
