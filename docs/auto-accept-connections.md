# 自动同意连接申请

`auto_accept=true` 仅自动审批收到的连接申请，不代表自动向所有附近节点申请连接。

- 被动发现（mDNS、私有 DHT、成员地址摘要）中的陌生节点只进入附近列表，不自动信任、不主动交换成员信息。
- 已有好友仍可通过发现和冷启动地址簿预热自动重连。
- 用户手动添加节点、连接码或连接种子会发送显式连接申请（info 协议 `connect_request=true`）；后台重连不携带该标记。
- 在自动同意设备上删除成员仍立即生效。被删除成员再次**手动申请**时，自动清除删除记录并恢复信任，无需先被拒绝一次。
- 后台发现、重连和陈旧记录不能越过删除保护。关闭自动同意时仍需要人工批准。

## 兼容边界

新增字段可被旧版忽略，不影响已有好友正常交换信息。被删除成员的“显式重新申请”需要申请端也升级到支持 `connect_request` 的版本；旧版没有区分手动申请与后台重连的能力，因此仍沿用删除告知/人工批准流程，避免后台重试自动恢复已删除成员。

## 验证

`go test ./pkg/serverless ./sdk/go/lanet -count=1`

回归覆盖被动发现和出向不触发审批、真实入向自动同意、删除后后台握手不恢复、显式申请直接恢复，以及自动同意关闭与数据库写入失败的保护。
