入向防火墙

统一管控三类入向：端口转发（TCP）、TUN 虚拟网卡（TCP/UDP）、应用流（libp2p 协议）。

局域网端口转发

群内成员访问「本节点虚拟 IP : Listen」时，转发到局域网设备 Target。本节点同时在 Listen 端口开监听并代理到 Target——容器节点没有真实服务监听时（如转发宿主上其他容器的服务），这样 http://虚拟IP:端口 才能直接访问。

节点配置 保存后重启程序生效

写入程序同目录 lanet.json，保存后重启程序生效。控制台默认仅本机可访问（127.0.0.1）；改为 0.0.0.0:8900 允许远程时，请务必同时设置控制台密码。

最长 分钟后自动关闭 未启用
公共 DHT 默认关闭。开启后仅用于跨网冷启动找「自己人」：连上同群成员立即自动退出；到时限仍未连上也自动退出。开关表示配置意图（保存后下次启动自动开启），右侧徽标显示本轮实际运行状态——两者独立，进程自动退出不会改动开关。
开启后，陌生节点必须先经你同意（类似加好友）才能互连；同意一次即永久信任，之后自动重连。关闭则相同网络密钥的节点可直接互连。
供无人值守的中央服务器 / 种子节点使用：开启后陌生节点无需人工审批即可互连。普通客户端不建议开启（等于放弃审批这道安全边界）。
