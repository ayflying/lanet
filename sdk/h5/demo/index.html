Lanet H5 节点 demo（单文件直引）

本页只引一个文件：../dist/lanet-h5.min.js，加载后全局 Lanet 即可用—— 免 npm、免打包器、免 importmap。服务端配合 Go echo 节点： go run ./app/agent/cmd/pvn-web-echo（启动日志里会打印邀请码）。

没找到 dist/lanet-h5.min.js（）
先在 sdk/h5 目录里构建一次：
npm install && npm run build
然后刷新本页。若不想构建，改用 importmap.html（零构建，依赖走 CDN）。
